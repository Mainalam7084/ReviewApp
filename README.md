# ResTrack 🍽️

**ResTrack** is a modern, dynamic web application designed to help food lovers track their culinary journey. It allows users to save, rate, and review every restaurant they visit, creating a personal gastronomic passport.

## ✨ Features

-   **User Authentication**: Secure Login and Sign Up functionality.
-   **Personal Dashboard**: A beautiful, glassmorphism-styled dashboard to view your collection.
-   **Add Memories**: Easily add new restaurants with:
    -   Name & Location
    -   Star Rating (1-5)
    -   Personal Review
-   **Google Maps Integration**: One-click access to view the restaurant location on Google Maps.
-   **Data Persistence**: All data is saved locally in your browser, so you never lose your list.
-   **Responsive Design**: Works perfectly on desktop and mobile devices.

## 🛠️ Technology Stack

-   **HTML5**: Semantic structure.
-   **CSS3**: Custom styling with a premium "Dark Mode" and Glassmorphism aesthetic.
-   **JavaScript (ES6+)**: Modular architecture for robust logic.
    -   `modules/auth.js`: Authentication handling.
    -   `modules/storage.js`: LocalStorage management.
    -   `modules/ui.js`: Dynamic DOM manipulation.

## 🚀 How to Use

1.  Clone the repository.
2.  Open `index.html` in your browser.
3.  Sign up for an account.
4.  Start adding your favorite restaurants!
